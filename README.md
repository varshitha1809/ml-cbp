# Sketch2Draw AI

Sketch2Draw AI is a local sketch-to-image web application. Draw on an interactive canvas, add an optional text prompt, and send the sketch to a FastAPI backend that runs Stable Diffusion with ControlNet to generate an image.

The interface also includes workspace controls and a lightweight practice-session history. The app is an evolving prototype; its stage labels and score cards are not generated by a drawing-evaluation model.

## Features

- Freehand canvas drawing with mouse, pen, or touch
- Brush size and color controls
- Undo, redo, clear, and export
- Optional reference-image overlay and drawing grid
- Optional text prompt for image generation
- FastAPI endpoint for model-backed generation
- Generated-image preview and recent session records stored in browser local storage
- Backend health indicator in the frontend

## Technology

- **Frontend:** React 18, Vite, HTML Canvas API
- **Backend:** FastAPI, Pillow
- **Image generation:** PyTorch, Hugging Face Diffusers, Stable Diffusion 1.5 and ControlNet
- **Sketch preprocessing:** HED from `controlnet_aux`

## Requirements

- Node.js and npm
- Python 3.10 or a compatible version for the pinned backend dependencies
- Internet access for the first download of the model weights
- Enough disk space and memory for Stable Diffusion and ControlNet
- A compatible GPU is recommended; inference can fall back to CPU, which may be very slow

The model code uses Apple MPS when available and otherwise selects CPU. NVIDIA CUDA is not currently selected by the model handler.

## Run on Windows

Open two PowerShell terminals from the project directory.

### 1. Install frontend dependencies

```powershell
Set-Location .\frontend
npm install
```

### 2. Start the frontend

```powershell
Set-Location .\frontend
npm run dev
```

Vite prints the local URL, normally `http://localhost:5173`.

### 3. Install backend dependencies

In a separate terminal:

```powershell
Set-Location .\backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

If PowerShell blocks virtual-environment activation, either use the Python executable directly at `.\.venv\Scripts\python.exe` or adjust the execution policy for the current user according to your local security requirements.

### 4. Start the API

```powershell
Set-Location .\backend
.\.venv\Scripts\python.exe -m uvicorn app:app --reload --host 127.0.0.1 --port 8000
```

API documentation is available at `http://localhost:8000/docs`. The frontend expects the API at `http://localhost:8000`.

## Use the application

1. Start the frontend and backend.
2. Draw on the canvas and optionally adjust the brush or guides.
3. Enter a prompt describing the intended image.
4. Select **Generate image** to submit the canvas to the backend.
5. Save a practice session to the browser's local storage.

## API

### `GET /health`

Returns backend health and the GPU information currently exposed by the backend.

### `GET /models/status`

Reports whether the generation pipeline has been loaded.

### `POST /generate`

Accepts multipart form data:

- `file`: sketch image
- `prompt`: optional text prompt

The response contains the generated PNG as a base64 string along with generation metadata. Model downloads or inference can fail if required packages, weights, memory, or compatible hardware are unavailable; failures are returned as API errors, not substituted with generated mock images.

## Current limitations

- Stage selection is UI scaffolding and does not yet produce image-derived drawing instructions.
- The displayed scores and feedback are not computed from a learner drawing; do not treat them as measured similarity or AI feedback.
- Saved sessions are stored only in the current browser's local storage; there is no account or backend database.
- The frontend currently submits the drawing canvas to the generation endpoint; reference-image upload and a contour-analysis API are not implemented.
- There is no custom model training pipeline or bundled model checkpoint.
- Model inference has not been verified on every OS, Python version, or GPU type. The declared PyTorch setup may need adjustment for your hardware.
