A guided process

Four stages, one drawing

Each step builds on contours generated by the existing image-to-sketch model.

1

Block It In

Start with the largest shapes. Lightly sketch the basic proportions and use guide lines to position the main features.

2

Find the Form

Follow the main outline, paying attention to curves, corners, and the proportions established in the first stage.

3

Define the Subject

Add the important details inside the outline. Check their positions and sizes against the main shape.

4

Finish the Sketch

Refine the visible lines, remove unnecessary construction guides, and compare the finished sketch with the reference.
